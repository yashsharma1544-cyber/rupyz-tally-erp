============================================================
GOOGLE SERVICE ACCOUNT SETUP — for the Tally Targets refresh
============================================================
One-time, ~10 minutes. Gives your Vercel app read access to the Google Sheet.

------------------------------------------------------------
PART A — Create the service account + key
------------------------------------------------------------
1. Go to https://console.cloud.google.com/
2. Top bar → project dropdown → "New Project".
   Name: "sushil-erp-sheets"  → Create. Wait ~20s, then select it.

3. Enable the Sheets API:
   - Search bar (top) → type "Google Sheets API" → open it → ENABLE.
   (Optional but harmless: also enable "Google Drive API" the same way.)

4. Create the service account:
   - Search "Service Accounts" → open → "+ CREATE SERVICE ACCOUNT"
   - Name: "tally-sheet-reader" → CREATE AND CONTINUE
   - Role: skip (click CONTINUE) → DONE

5. Make a key:
   - Click the service account you just made (its email looks like
     tally-sheet-reader@sushil-erp-sheets.iam.gserviceaccount.com)
   - Tab "KEYS" → ADD KEY → Create new key → JSON → CREATE
   - A .json file downloads. KEEP IT SAFE — this is the credential.

------------------------------------------------------------
PART B — Share the sheet with the service account
------------------------------------------------------------
6. Open your Google Sheet:
   https://docs.google.com/spreadsheets/d/17aCiH1F_N7ljsvPJeRoL4801eg9cM8HQMf8tVisvXwg/edit
7. Click "Share" (top right).
8. Paste the service account email (from step 5, ends in .iam.gserviceaccount.com)
9. Set it to "Viewer" → uncheck "Notify people" → Share.
   (The robot account can now read this sheet.)

------------------------------------------------------------
PART C — Put the credentials in Vercel
------------------------------------------------------------
10. Open the downloaded JSON. You need two values from it:
    - "client_email"
    - "private_key"   (a long multi-line string starting -----BEGIN PRIVATE KEY-----)

11. In Vercel → your project → Settings → Environment Variables, add:

    GOOGLE_SHEETS_CLIENT_EMAIL   = (the client_email value)
    GOOGLE_SHEETS_PRIVATE_KEY    = (the entire private_key value, including the
                                    BEGIN/END lines)
    TALLY_SHEET_ID               = 17aCiH1F_N7ljsvPJeRoL4801eg9cM8HQMf8tVisvXwg

    IMPORTANT for the private key: Vercel env vars are single-line. When you paste
    the private_key, the newlines show as literal \n inside the JSON — that's fine,
    paste it exactly as it appears in the JSON file (with the \n sequences). The code
    will convert \n back to real newlines. If you instead paste a version with REAL
    line breaks, that also works in Vercel's multiline box — but the JSON \n form is
    safest.

12. Set them for Production (and Preview if you want). Save.
    Redeploy so the new env vars take effect.

------------------------------------------------------------
WHICH TAB / RANGE
------------------------------------------------------------
Tell me the exact TAB NAME of the sheet that holds the sales data (bottom tabs in
Google Sheets). I'll default to the first tab if you don't specify. The columns I
detected are:
  Date | Voucher No | Party Name | Item | Qty | Rate | Amount | CGST | SGST | IGST |
  Round Off | Total | Narration | GUID | AlterID | Qty (Kg) | Party Group | Root Group

When Part A–C are done, tell me and I'll confirm the refresh endpoint matches your
env var names. The endpoint will read TALLY_SHEET_ID using the service account and
